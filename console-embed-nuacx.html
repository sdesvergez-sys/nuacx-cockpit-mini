Console de test (Cockpit mini)

Intégration CRM du Cockpit (iframe)

Teste le pont d'intégration minimal exposé par /workspace : clic-to-call, screen-pop, journalisation d'interaction et affichage compact. Inspirée dans l'esprit de la console Genesys Cloud Embeddable Framework, mais avec le vocabulaire et le périmètre propres à NUACX — voir docs-site/docs/technique/cockpit-embarque.md pour le contrat complet.

Connexion

1Charger le Cockpit

Aucun jeton à fournir ici : l'iframe se charge sans authentification, détecte qu'elle est embarquée (Sec-Fetch-Dest: iframe) et affiche son propre écran « Se connecter » — un clic ouvre une popup top-level (/workspace/launch, réutilise la connexion NUACX habituelle, OTP compris) qui mint le jeton et le repasse au Cockpit embarqué tout seul. Voir docs-site/docs/technique/cockpit-embarque.md pour le détail du mécanisme.

Pont inactif

Décochez « Mode compact » pour comparer, dans le même panneau 420px, le rendu sans mode=mini (sidebars dans l'état de leur dernier cookie) — démontre pourquoi ce paramètre compte pour un panneau CRM étroit. Popup bloquée par le navigateur ? Le bouton « Se connecter » du Cockpit affiche le message d'erreur correspondant, autorisez les pop-ups pour cette page puis recliquez « Charger » pour recommencer.

Actions

2Clic-to-Call

Envoie nuacx:clickToCall à l'iframe — compose le numéro comme si l'agent l'avait tapé lui-même. Nécessite un agent déjà enregistré (SIP) dans le Cockpit chargé ci-contre.

Événements reçus

nuacx:ready

Émis une fois au chargement du Cockpit — confirme que le pont est actif.

nuacx:screenPop

Émis à la présentation d'un appel entrant — numéro, nom, correspondance annuaire si trouvée.

nuacx:interactionLogged

Émis à la soumission du code de conclusion — synthèse destinée à la journalisation CRM.

Cockpit embarqué
Pas encore chargé — cliquez sur « Charger ».
